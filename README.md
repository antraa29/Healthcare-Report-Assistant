# Healthcare Report Assistant

An AI-powered healthcare report analysis application that extracts
laboratory values from medical reports and generates an easy-to-understand
summary using Retrieval-Augmented Generation (RAG) and Google Gemini.

## Features

- Upload medical PDF reports
- Extract text from PDF documents
- Extract patient and laboratory information
- Retrieve relevant laboratory reference information
- Generate grounded explanations using RAG
- Use Gemini for natural-language summarization
- Provide a user-friendly Streamlit interface
